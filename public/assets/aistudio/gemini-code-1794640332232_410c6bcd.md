# Project Specification: Nivet's DocuScan AI

## 1. Executive Summary
**Nivet's DocuScan AI** is a zero-backend, privacy-first browser web application for intelligent Optical Character Recognition (OCR) and structured document extraction. Powered by Google's multimodal Gemini API (`gemini-2.5-flash`), it transforms raw images, screenshots, handwritten notes, and PDFs into clean prose, structured Markdown tables, or validated JSON schemas—all processed directly from the client browser without external databases or authentication walls.

---

## 2. Technical Architecture & Constraints
- **Frontend Stack:** React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **AI SDK:** `@google/genai` using model `gemini-2.5-flash`.
- **Authentication & Security:** Uses `process.env.API_KEY` injected by the runtime environment. No backend servers, no user sign-ups, and no cloud storage.
- **Client Persistence:** Uses `window.localStorage` (`docuscan_session_history`) to temporarily store recent extractions (metadata + extracted text, excluding heavy base64 blobs to prevent quota overflow) with a 1-click **"Clear History"** action.
- **Supported Input Formats:** `image/png`, `image/jpeg`, `image/webp`, and `application/pdf` via base64 `inlineData`.

---

## 3. Core Features & Functional Requirements

### 3.1. Smart Extraction Modes
Users can select or switch modes before or after uploading a file (re-running extraction on demand):
1. **Clean Plain Text (`plain`)**
   - Extracts body text into coherent paragraphs.
   - Automatically repairs broken line wraps from multi-column scans and strips OCR artifacts/headers/footers where appropriate.
2. **Preserve Tables & Layout (`markdown`)**
   - Detects tabular structures, forms, and key-value pairs.
   - Reconstructs data using valid GitHub Flavored Markdown (GFM) tables, headings, and lists.
3. **Handwriting & Notes Mode (`handwriting`)**
   - Uses specialized prompt instructions tuned for cursive script, whiteboard photos, lecture notes, and rough sketches, inferring context where handwriting is messy.
4. **Receipt / Invoice JSON Extractor (`json`)**
   - Uses Gemini `responseSchema` / `responseMimeType: "application/json"` to guarantee structured JSON output containing:
     - `merchantName` (string)
     - `date` (string)
     - `currency` (string)
     - `lineItems` (array of `{ description, quantity, unitPrice, total }`)
     - `subtotal` (number)
     - `tax` (number)
     - `totalAmount` (number)
   - Renders both a visual **Receipt Summary Card** and raw copyable/downloadable JSON.

### 3.2. Multi-Modal Ingestion & Live Preview
- **Upload Methods:**
  - Drag-and-drop zone with active drag-over visual feedback.
  - Standard OS file picker (`<input type="file">`).
  - **Global Clipboard Listener (`Ctrl+V` / `Cmd+V`):** Captures pasted screenshots directly from the user's clipboard and loads them immediately.
- **Instant Sample Generator ("Try with Sample Receipt / Note"):**
  - Programmatically draws a realistic mock receipt or handwritten-style note onto an offscreen HTML5 `<canvas>`, converts it to a PNG data URL, and feeds it into the pipeline so users can test the app in 1 click.
- **Interactive Document Viewer:**
  - Displays uploaded images with Zoom In / Zoom Out / Reset Fit controls.
  - Displays uploaded PDFs via an embedded `<iframe type="application/pdf">` or `<embed>` previewer.

### 3.3. Post-Extraction Workspace & Actions
- **Editable Output Area:** Users can manually edit extracted text directly inside the workspace to fix edge-case typos prior to exporting.
- **View Toggles:** Switch seamlessly between **Raw Text/Code Editor** and **Rendered Preview** (Markdown preview for text/tables; Summary Card for JSON).
- **Quick Actions Toolbar:**
  - **Copy to Clipboard** (with 2-second `"Copied!"` checkmark feedback).
  - **Export Downloads:** `.txt`, `.md`, and `.json` file generators via Blob URLs.
- **Live Telemetry Footer:** Real-time calculation of **Word Count**, **Character Count**, and **Estimated Reading Time** (`Math.ceil(words / 200)` min).

## 4. UI/UX Layout Specification
- **Top Navigation Bar:**
  - Brand identity: **Nivet's DocuScan AI** with subtle scanner/sparkle icon.
  - Session History drawer toggle (shows count of saved items + Clear History button).
  - Light / Dark mode theme switcher (persisted in `localStorage`).
- **Main Split-Screen Workspace (Desktop: 50/50 Grid; Mobile: Stacked):**
  - **Left Pane (Input & Preview):**
    - Compact pill selector for the 4 Extraction Modes.
    - Dropzone / Preview Canvas (switches dynamically between the empty dropzone state with `"Try with Sample Receipt"` button and the active zoomed document preview with `"Replace File"` button).
    - Primary CTA button: **"Extract Text"** (or **"Re-Extract with [Mode]"**).
  - **Right Pane (Output & Export):**
    - Top Action Bar: View Toggle (`Editor` | `Preview`), `Copy`, `Download .txt`, `Download .md`, `Download .json`.
    - Content Area: Loading skeleton with animated progress message (*"Analyzing document layout..."*), editable `<textarea>`, or formatted Markdown/Receipt Card view.
    - Bottom Status Bar: Word count, character count, reading time, and active mode badge.
